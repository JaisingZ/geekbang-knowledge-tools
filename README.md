# geekbang-knowledge-tools

极客时间已登录内容检索与摘要工具集。

## 适用范围

- 只针对 `time.geekbang.org`
- 依赖当前已登录的浏览器会话
- 输入可以是文章 URL，也可以是当前已打开的极客时间标签页

## 输出约定

- 标题
- 正文核心论点
- 结构化要点
- 评论区高频观点 / 争议点
- 可选：上一篇 / 下一篇

默认不输出长段原文，只保留必要短引述和高密度摘要。

## 目录

- `skills/geektime-article-summarizer/SKILL.md`: 核心 skill
- `examples/`: 最小使用示例
- `examples/924817-summary.md`: 当前文章的实际摘要示例
